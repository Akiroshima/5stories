```
Models/

├── Tetromino.cs                  # Падающие фигуры (I, O, T, S, Z, J, L)

                                  # IGameEngine, IGameObserver

```
Services/

## 🎯 РЕАЛИЗОВАННЫЕ ТРЕБОВАНИЯ

### ✅ Из пользовательских историй:
1. **История 1**: Управление падающими фигурами
   - ✓ Game.MovePieceLeft(), MovePieceRight(), MovePieceDown()

   - ✓ Полная система коллизий и валидации

2. **История 2**: Сохранение прогресса
   - ✓ GamePersistenceService.SaveGameAsync()
   - ✓ Формат: текстовый файл с ключ=значение и битовой картой поля
   - ✓ Сохранение состояния поля и всех параметров

3. **История 3**: Загрузка игры
   - ✓ GamePersistenceService.LoadGameAsync()
   - ✓ Полное восстановление состояния
   - ✓ Продолжение игры после загрузки

4. **История 4**: Таблица рекордов
   - ✓ LeaderBoardService с TOP-10 системой
   - ✓ Текстовый файл хранения
   - ✓ DataGrid отображение в UI

5. **История 5**: Простая структура данных
   - ✓ Текстовые файлы (простой CSV-подобный формат)
   - ✓ Легко расширяется (добавить уровни, настройки)

### ✅ Архитектурные требования:
- ✓ **Классы** - 13 доменных классов + сервисы
- ✓ **Наследование** - ViewModelBase, интерфейсы
- ✓ **Агрегация** - Game содержит GameBoard, Score, Tetromino
- ✓ **Интерфейсы** - IGamePersistence, ILeaderBoardManager, IGameObserver, ICommand, INotifyPropertyChanged
- ✓ **MVVM паттерн** - полная реализация с WPF
- ✓ **Data Binding** - привязка всех данных через XAML
- ✓ **Паттерны** - Observer, Command, Repository, MVVM
